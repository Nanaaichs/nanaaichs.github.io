## Overview

This project develops an end-to-end simulation framework for 5G NR Non-Terrestrial Networks in LEO satellite scenarios. The scope covers initial access, downlink physical channels, and receiver-side synchronization and compensation.

## Problem

LEO satellite communication introduces large propagation delay, strong and time-varying Doppler shift, and rapidly changing satellite-ground geometry. The project studies how NR physical-layer procedures operate under these NTN-specific conditions.

## My Contribution

- Physical-layer system modeling and simulation
- NTN access-procedure integration
- Doppler modeling and compensation
- Timing and carrier-frequency synchronization
- Channel estimation, phase tracking, and equalization
- System visualization and reproducible simulation workflows

## System Scope

- SSB transmission and detection
- PBCH processing and system-information acquisition
- PRACH random access
- PDCCH and PDSCH processing
- Doppler pre-compensation and residual CFO estimation
- OFDM demodulation
- DM-RS/PT-RS-assisted receiver processing
- MMSE equalization and soft demodulation
